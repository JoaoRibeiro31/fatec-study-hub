# Repositório Acadêmico FATEC

Este repositório reúne atividades práticas, exercícios, resumos de aula e projetos desenvolvidos ao longo do curso na **Faculdade de Tecnologia (FATEC)**.  
O objetivo é centralizar conteúdos acadêmicos para facilitar o acesso, organização e compartilhamento.

## 📂 Estrutura de Pastas

A organização segue o padrão:

- `semestre-X/` → Cada semestre do curso
  - `disciplina/` → Matéria específica
    - `praticas/` → Exercícios e trabalhos práticos
      - `AAAA-MM-DD-tema/` → Pasta com atividades de uma data e tema específico
    - `resumos/` → Resumos de aula em formato texto/markdown
      - `AAAA-MM-DD-tema.md` → Arquivo com resumo de uma aula específica
    - `projetos/` → Projetos maiores ou integradores
      - `nome-do-projeto/` → Pasta dedicada ao projeto

### Exemplo

semestre-1/
├── algoritmos/
│   ├── praticas/
│   │   ├── 2026-08-13-introducao/
│   │   └── 2026-08-20-estruturas-condicionais/
│   ├── resumos/
│   │   ├── 2026-08-13-introducao.md
│   │   └── 2026-08-20-estruturas-condicionais.md
│   └── projetos/
│       └── projeto-integrador-1/


## 🎯 Objetivo
- Servir como apoio ao estudo individual e coletivo  
- Facilitar a revisão de conteúdos  
- Documentar a evolução acadêmica ao longo do curso  
- Centralizar materiais de diferentes disciplinas em um só lugar
